# Benchmarks

This folder contains the benchmarks for `mstlo` used to generate the results from the paper *MSTLO: Efficient Online Monitoring of Signal Temporal Logic* at the 26th International Conference on Runtime Verification (RV26).

> For the dockerized benchmarks used at the **Tool Showcase Submission**, please refer instead to: [(https://github.com/INTO-CPS-Association/mstlo-benchmarks)](https://github.com/INTO-CPS-Association/mstlo-benchmarks)

Each benchmark is contained in its own subfolder, with a `README.md` file that explains the benchmark and how to run it. Each benchmark has a single `.sh` file that runs the benchmark and generates the results. Note that the Rust benchmarks files are located in the [mstlo/benches](../mstlo/benches/) folder, and the Python benchmarks are located in the benchmark subfolders.

## Synthetic Signal

This benchmark evaluates the performance of the `mstlo`, `mstlo-python`, and `RTAMT` libraries in monitoring and analyzing synthetic signals generated for testing purposes. The benchmark includes a set of predefined STL formulas and signal data, allowing for a comprehensive comparison of the libraries' capabilities. Notably, it includes an investigation of how the performance scales with the temporal depth of the formulas in the different semantics. It also reports the memory usage of the different semantics (only in mstlo).

## Incubator

This benchmark is based on the Incubator Case study (see: [https://arxiv.org/abs/2102.10390](https://arxiv.org/abs/2102.10390)). It provides data from a simulation of a temperature control system for an incubator. The benchmark evaluates the performance of the `mstlo`, `mstlo-python`, and `RTAMT` libraries in monitoring and analyzing the temperature data generated by the incubator simulation. It also records the memory footprint of the native monitor after every update, and plots it against the signal being monitored.
